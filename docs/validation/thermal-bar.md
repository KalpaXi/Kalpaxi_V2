# Validation: thermal bar

## Problem

**Case A, conduction:** bar with fixed temperatures T1 and T2 at the ends, sides insulated.
- Temperature is linear along the bar; heat flow q = k·A·(T1 − T2) / L

**Case B, thermal stress:** bar fully restrained at both ends, uniform temperature rise ΔT.
- Axial stress σ = −E·α·ΔT (compressive)

**Suggested values:** steel, L = 100 mm, k = 50 W/m·K, α = 12×10⁻⁶ /K, ΔT = 100 K.
