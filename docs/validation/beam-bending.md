# Validation: cantilever beam

## Problem

Rectangular cantilever, fixed at one end, point load **P** at the free end.

**Hand calculation**
- Tip deflection: δ = P·L³ / (3·E·I)
- Maximum bending stress at the fixed end: σ = M·c / I = P·L·(h/2) / I
- I = b·h³ / 12

**Suggested values:** L = 200 mm, b = 20 mm, h = 10 mm, P = 100 N, steel E = 210 000 MPa.
