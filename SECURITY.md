# Security policy

## Supported versions

| Version | Security fixes |
|---|---|
| 2.x | ✅ Yes |
| Older than 2.0 | ❌ No |

## Reporting a vulnerability

Please **do not** report security problems in public issues.

Report them privately, in either way:

- Email **admin@kalpaxi.in** with the subject line `SECURITY`
- Or use GitHub's **Report a vulnerability** button on the repository's *Security* tab

Please include:

- the KalpaXi version and operating system
- what the problem is and what someone could do with it
- steps to reproduce it

## What happens next

| Step | Target time |
|---|---|
| We confirm we received your report | Within 3 working days |
| First assessment | Within 10 working days |
| Fix released, depending on severity | As soon as practical |

We will credit you in the release notes if you wish.

## Scope

In scope: the KalpaXi desktop software, the installer, and the registration
service at `register.kalpaxi.in`.

Out of scope: problems in third-party programs (Gmsh, CalculiX, OpenCascade etc.).
Please report those to their own projects.
